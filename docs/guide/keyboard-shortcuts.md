# Keyboard shortcuts

**Mod** is Ctrl+Shift on Windows and Linux and ⌘ on macOS. Plain Ctrl+letter, Tab, Alt+letter and the other keys a device CLI uses always go to the device; app shortcuts never take them (see [Terminal › The keymap](terminal.md#the-keymap)).

`Mod+/` shows the cheat sheet in the app, and **Settings › Keyboard** rebinds any shortcut marked rebindable. Shortcuts match the physical key, so they work on any keyboard layout.
