# Project direction

Hopline puts the evidence for a network incident beside the model that helps investigate it. A useful addition makes a device easier to understand, a finding easier to verify, or a proposed change easier to review.

| Area | Where contributions help |
| --- | --- |
| Evidence | Add compact, synthetic samples where a parser drops a routing context, misreads a column, or misses a vendor’s output. Include the command and the expected rows. |
| Privacy | Add fixtures for labels that survive masking. Show which hostname or description should disappear and which interface state, counter or route should remain usable. |
| Device support | Check a platform’s command classification and prompt handling against real equipment. Record the OS version and a sanitized transcript. |
| Distribution | Verify signed Windows and macOS packages and make the update feed readable by installed copies. The current downloadable builds cover Windows and Linux. |
